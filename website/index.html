How the tracked register is changing

Recommendations · count

Opening outstanding + newly issued + reopened / review transitions − implemented − other closures = closing outstanding. Disappearance from a report never counts as closure.

Observed implementation rate by entity

Implemented / eligible BOA assessments in this audit year. Joint recommendations appear under each responsible entity but count once in overall totals. These breakdowns overlap and must not be added.

Annual assessment population

Only the latest BOA annex observation per recommendation in the selected audit year enters this rate. Unresolved assessments are excluded. Other closures are in the denominator but are not implemented.
